# BadMelon Documentation

BadMelon is a recipe-based pantry management system. The product helps families plan meals, track what food they already have, and buy only what they need.

This documentation starts with requirements before implementation choices. The intent is to make product decisions explicit, then use those decisions to guide the design system, API, and frontend.

## Working Decisions

These docs should evolve as the project becomes clearer. For now, requirements are grouped into:

- **Must have:** Core behavior needed for the first useful version.
- **Should have:** Important behavior that can follow once the core flow works.
- **Could have:** Useful enhancements that should not block the initial build.
- **Open questions:** Decisions that need product or technical judgment before implementation.
